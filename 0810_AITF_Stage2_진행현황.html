잔여 과제 (30% → 100%)
  1. 3개 도메인 규약 확정 — 요청 식별자 체계 · 작업 대상 지정 방식 · 산출물 경로 · 종료 조건이 mes에만 있음
  2. SRS 흐름 범용화 — 현재 경로만 도메인화되고 절차는 MES 전용. 도메인을 데이터로 분리하는 후속 과제
  3. 도메인별 rules 작성 — lv2·platform·sap의 rules/가 비어 있어 참조할 규칙이 없음
  4. 단위테스트결과서 템플릿 — mes 외 도메인에 템플릿·생성 스크립트 미비
  5. handbook 착수 — 시스템 전체 매뉴얼은 작성 방식·템플릿 결정이 선행 과제
  6. 표준화 설계서 정본화 — 현재 표준은 저장소 내 ADR·README로만 존재. 센터 승인 문서 형태로 정리 필요(8월)
설계 근거는 ADR 31건으로 관리 — 채택된 결정은 고치지 않고 새 ADR로 대체(append-only)해 "왜 그렇게 정했는지"의 역사를 보존한다.
